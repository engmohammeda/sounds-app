# 🌙 أصوات وترددات النوم - Sleep Sounds & Frequencies

تطبيق أندرويد احترافي لأصوات وترددات النوم والتركيز والتأمل. جميع الأصوات مولّدة برمجياً باستخدام محرك صوتي متقدم بدون الحاجة لملفات صوتية خارجية.

## 📱 لقطات الشاشة

التطبيق يتميز بتصميم داكن هادئ مع ألوان متناسقة لكل تصنيف.

## ✨ المميزات الرئيسية

### 🔊 محرك صوتي متقدم
- **توليد صوتي برمجي كامل** - جميع الأصوات تُولّد في الوقت الفعلي باستخدام `AudioTrack`
- **28 نوع موجة مختلف** - من الموجات الأساسية إلى المحاكاة المعقدة
- **80+ صوت وتردد** موزعة على 9 تصنيفات
- **خلط الأصوات** - تشغيل عدة أصوات في وقت واحد مع تحكم مستقل بالصوت

### ⏰ مؤقت النوم
- **11 خيار زمني** - من 5 دقائق إلى 3 ساعات + وضع بلا حدود
- **تخفيض تدريجي** - يخفض الصوت تدريجياً خلال آخر 15 ثانية
- **إيقاف تلقائي** - يوقف جميع الأصوات عند انتهاء المؤقت
- **عرض دائري متحرك** للوقت المتبقي

### 📚 مكتبة شاملة (9 تصنيفات)

| التصنيف | الأصوات | الوصف |
|---------|---------|-------|
| 🌙 النوم | 10 | موجات دلتا، تهويدة، درون، نبضات القلب |
| 🎯 التركيز | 8 | موجات بيتا/غاما، نبضات إيزوكرونيك |
| 💼 العمل | 7 | موجات ألفا، ضوضاء بيضاء/بنية |
| 🧘 الهدوء | 8 | موجات ثيتا، مطر، رياح، أوعية تبتية |
| 🌿 الطبيعة | 9 | محيط، مطر، رعد، غابة، نار، طيور |
| 🕉️ التأمل | 11 | ترددات الشاكرات السبع، شومان، أوم |
| 🧠 ترددات ثنائية | 12 | دلتا/ثيتا/ألفا/بيتا/غاما |
| 📻 ضوضاء بيضاء | 8 | بيضاء/وردية/بنية، مروحة، مكيف |
| 🌌 محيطي | 8 | فضاء، تحت الماء، كهف، قطار |

## 🏗️ البنية التقنية

### الهيكل المعماري
```
app/src/main/java/com/agon/app/
├── MainActivity.kt              # نقطة الدخول + التنقل
├── data/
│   ├── SoundModels.kt           # نماذج البيانات + مكتبة الأصوات
│   └── AudioEngine.kt           # محرك التوليد الصوتي
├── viewmodel/
│   └── SoundViewModel.kt        # إدارة الحالة + المنطق
└── ui/
    ├── theme/
    │   ├── Color.kt              # ألوان مخصصة (ليلي/نهاري)
    │   └── Theme.kt              # ثيم Material 3
    └── screens/
        ├── HomeScreen.kt         # الشاشة الرئيسية
        ├── CategoryScreen.kt     # شاشة التصنيف + عناصر القائمة
        ├── TimerScreen.kt        # مؤقت النوم
        ├── MixerScreen.kt        # خلاط الأصوات
        ├── FavoritesScreen.kt    # المفضلة
        └── SettingsScreen.kt     # الإعدادات + دليل الترددات
```

### التقنيات المستخدمة
- **Kotlin 2.2.21** - لغة البرمجة
- **Jetpack Compose** - واجهة المستخدم التصريحية
- **Material Design 3** - نظام التصميم
- **Android AudioTrack** - التوليد الصوتي في الوقت الفعلي
- **Navigation Compose** - التنقل بين الشاشات
- **ViewModel** - إدارة الحالة
- **Coroutines** - العمليات غير المتزامنة

## 🎨 نظام الألوان

التطبيق يستخدم نظام ألوان ليلي مخصص:
- **الخلفية**: أزرق داكن عميق `#0B0E1F`
- **الأساسي**: بنفسجي مزرق `#7B8CFF`
- **الثانوي**: لافندر ناعم `#B8C4FF`
- **التمييز**: كهرماني دافئ `#FFB74D`

كل تصنيف له لون مميز خاص به لسهولة التعرف.

## 📖 دليل الترددات

| النطاق | التردد | التأثير |
|--------|--------|--------|
| دلتا | 0.5-4 Hz | نوم عميق، شفاء، تجديد |
| ثيتا | 4-8 Hz | تأمل، إبداع، استرخاء |
| ألفا | 8-13 Hz | هدوء، تعلم، حالة تدفق |
| بيتا | 13-30 Hz | تركيز، انتباه، يقظة |
| غاما | 30-100 Hz | وعي فائق، إدراك، ذروة |

### ترددات الشاكرات (Solfeggio)
| الشاكرا | التردد | التأثير |
|---------|--------|--------|
| الجذر | 396 Hz | التحرر من الخوف |
| العجز | 417 Hz | التغيير والتحول |
| الضفيرة الشمسية | 528 Hz | الحب والشفاء |
| القلب | 639 Hz | التواصل والعلاقات |
| الحلق | 741 Hz | التعبير والحدس |
| العين الثالثة | 852 Hz | الوعي الروحي |
| التاج | 963 Hz | الاتصال الكوني |
